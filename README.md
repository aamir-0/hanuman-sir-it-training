# Hanuman Sir IT Training

Static website for hanuman, an independent IT trainer specializing in Networking, VMware, and Azure AD/Entra ID.

## Tech Stack

- HTML5
- Tailwind CSS via CDN
- Vanilla JavaScript

## Project Structure

```text
/
├── index.html
├── about.html
├── contact.html
├── courses/          # Individual course pages
├── labs/             # Individual lab pages
├── assets/
│   ├── images/       # Site images
│   ├── icons/        # Site icons
│   └── pdfs/         # Downloadable documents
├── css/
│   └── style.css
├── js/
│   └── main.js
├── .gitignore
└── README.md
```

## Run Locally

Open `index.html` directly in a browser, or use the VS Code Live Server extension for local development.

## Deployment

Planned deployment: GitHub Pages. The deployment target can be updated if Netlify or Vercel is selected later.

## Branch Strategy

This is a solo static project, so work happens directly on `main` for now. A `dev` branch can be added when previewing changes before production becomes necessary.
